**Title:** I built a Python notebook comparing Itô vs Stratonovich stochastic calculus — here's what I learned

**Body:**

Hey everyone! I've been diving into stochastic differential equations (SDEs) and created an interactive notebook exploring the differences between Itô and Stratonovich calculus.

**ELI5 version:** When you have a system with random noise (like a particle bouncing around), there are two ways to mathematically define how that noise integrates over time. They give DIFFERENT answers, and picking the wrong one introduces systematic errors.

**The key difference:**
- Itô integral evaluates the function at the START of each interval
- Stratonovich integral evaluates at the MIDPOINT

This seems minor but has huge consequences:

1. **Chain rule**: In Stratonovich calculus, the ordinary chain rule df(X) = f'(X)dX works! In Itô, you need a correction term (the famous Itô formula with the ½f''(X)b²dt term).

2. **Physical meaning**: The Wong-Zakai theorem proves that if your "white noise" is actually the limit of smooth colored noise (which is true in real physics), the system converges to the Stratonovich solution.

3. **Conversion formula**: You can convert between them:
   a_Itô(x) = a_Strat(x) + ½b(x)b'(x)

**What I implemented:**
- Euler-Maruyama scheme (for Itô SDEs) — strong order 0.5
- Heun predictor-corrector scheme (for Stratonovich SDEs) — strong order 1.0
- Monte Carlo verification with 10,000 paths showing the bias from using wrong interpretation

The notebook includes geometric Brownian motion and a nonlinear multiplicative noise example with α=0.5.

**Interactive notebook:** https://cocalc.com/github/Ok-landscape/computational-pipeline/blob/main/notebooks/published/stratonovich_calculus.ipynb
