Boundary Element Method implementation for acoustic scattering:

The Kirchhoff-Helmholtz integral:
c(r)p(r) = p_inc(r) + ∫[G(∂p/∂n) - p(∂G/∂n)]dΓ

For sound-hard boundary (∂p/∂n = 0):
p(r)/2 = p_inc(r) - ∫p(r')(∂G/∂n')dΓ

With Green's function:
G = (i/4)H₀⁽¹⁾(kr)
∂G/∂n' = -(ik/4)H₁⁽¹⁾(kr)(∇r·n)/r

Results: ka=9.16, 91 boundary elements, validated against analytical Bessel/Hankel series with max error 8.4%.

### 5. Reddit (r/Python or r/computationalphysics)

**Title:** Boundary Element Method for Acoustic Scattering - BEM reduces 2D problem to 1D

**Body:**

I implemented the Boundary Element Method (BEM) to solve acoustic scattering from a rigid cylinder, and the results beautifully match analytical solutions.

**Why BEM is Special**

Unlike Finite Element Method (FEM) which discretizes the entire domain, BEM only discretizes the boundary. For a 2D problem, this means:
- FEM: 2D mesh of thousands of elements
- BEM: 1D boundary with ~100 elements

This dimensional reduction makes BEM particularly powerful for:
- Exterior problems (unbounded domains like acoustic radiation)
- Problems with infinite extent (no artificial truncation needed)
- Linear homogeneous PDEs with known Green's functions

**The Mathematics**

Starting with the Helmholtz equation for acoustic pressure:
∇²p + k²p = 0

Using Green's second identity, this becomes the Kirchhoff-Helmholtz boundary integral equation. For a sound-hard (rigid) scatterer with ∂p/∂n = 0, the integral equation simplifies to a linear system involving only surface pressure values.

**Implementation Details**

- Green's function: G(r,r') = (i/4)H₀⁽¹⁾(k|r-r'|) where H₀⁽¹⁾ is the Hankel function (represents outgoing waves)
- Discretization: Constant element collocation method
- System matrix: Dense N×N where diagonal term = 1/2 (from solid angle)
- Validation: Compared with analytical solution using Bessel/Hankel series

**Results**

Test case: Circular cylinder with radius a=1m, frequency 500 Hz (ka ≈ 9.16)
- Used 91 boundary elements (~10 per wavelength)
- Error vs analytical: < 1% mean, < 8.5% max
- Computation time: <1 second

**Physical Phenomena Captured**

The solution shows:
1. Shadow region behind cylinder (pressure reduction)
2. Bright spot on illuminated side (constructive interference)
3. Diffraction fringes (wave bending around obstacle)
4. Standing wave pattern in front

**Key Advantages of BEM**

✓ No domain truncation needed
✓ No absorbing boundary conditions
✓ Radiation condition automatically satisfied
✓ Reduced problem dimensionality
✓ High accuracy for smooth geometries

**Limitations**

✗ Dense system matrices (O(N²) storage, O(N³) solve)
✗ Singular integrals require special treatment
✗ Non-uniqueness at certain frequencies (need CHIEF or Burton-Miller formulation)
