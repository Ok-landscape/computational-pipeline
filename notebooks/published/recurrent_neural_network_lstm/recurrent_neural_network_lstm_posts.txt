Title: I built an LSTM from scratch in NumPy to understand how it solves the vanishing gradient problem

Body:
I've been studying recurrent neural networks and wanted to really understand why LSTMs work. So I implemented one completely from scratch using only NumPy.

**The Problem with Vanilla RNNs**

In a standard RNN, the hidden state updates as:
h_t = tanh(W * h_{t-1} + W * x_t)

During backpropagation, gradients get multiplied repeatedly. When the weight matrix has eigenvalues < 1, these gradients shrink exponentially - making it impossible to learn dependencies spanning many timesteps.

**How LSTMs Fix This**

LSTMs introduce a "cell state" that acts like a conveyor belt. Three gates control information flow:

1. **Forget gate (f)**: sigmoid that decides what to discard
2. **Input gate (i)**: sigmoid that decides what to store
3. **Output gate (o)**: sigmoid that decides what to output

The key equation is the cell state update:
C_t = f * C_{t-1} + i * C_new

When the forget gate is close to 1, gradients flow unchanged through time!

**My Implementation**

I built:
- LSTMCell class with forward() and backward() methods
- Full LSTM class with sequence processing
- Backpropagation Through Time (BPTT)
- Gradient clipping to prevent explosions

Trained it to predict sine wave sequences and it converged nicely.

**Key Learnings**
- Initialize forget gate bias to 1.0 (helps gradient flow)
- Use Xavier initialization for weights
- Gradient clipping is essential (I used clip value of 5.0)
- Numerically stable sigmoid matters for edge cases

Check out the full notebook with code and visualizations:
https://cocalc.com/github/Ok-landscape/computational-pipeline/blob/main/notebooks/published/recurrent_neural_network_lstm.ipynb

Happy to answer questions about the implementation!
