Just built a Random Forest classifier from scratch - no sklearn, just numpy!

The magic of ensemble learning:
- Take N bootstrap samples from your data
- Train a decision tree on each
- Let them vote on the final prediction

Why it works: Each tree sees different data + random feature subsets at each split. This decorrelates the trees, reducing overall variance.

The math: Var(ensemble) = rho * sigma squared + (1-rho)/B * sigma squared

Lower correlation rho = lower variance. Simple but powerful.

Implemented Random Forest from first principles in Python.

Core algorithm:
1. Bootstrap sample: ~63.2% unique observations per tree (1 - e to the power of -1)
2. At each split, randomly select m = sqrt(p) features
3. Split using Gini impurity: G(t) = 1 - sum(pk squared)
4. Aggregate via majority voting

Out-of-bag samples provide free validation - no need for separate holdout set.

Results on moons dataset: 96% test accuracy with 100 trees. Single tree: ~91%.

Title: Built Random Forest from Scratch in Python - Here's What I Learned

Body:

I implemented a complete Random Forest classifier using only NumPy to really understand how ensemble methods work. Here's the breakdown:

**What is Random Forest?**

Think of it like asking 100 different experts to vote on a decision. Each expert (decision tree) sees a slightly different version of the data and focuses on different features. The final answer is whatever most experts agree on.

**The Key Ideas:**

1. **Bootstrap Aggregating (Bagging)**: Each tree trains on a random sample WITH replacement. About 63% of data points appear in each sample - the rest become "out-of-bag" samples for free validation.

2. **Random Feature Selection**: At each split, only consider sqrt(total features) randomly chosen features. This decorrelates the trees.

3. **Gini Impurity**: Measures how "mixed" the classes are at a node. Formula: G = 1 - (p0 squared + p1 squared). Pure node = 0, maximum impurity = 0.5 for binary classification.

**Why It Works (The Math):**

Ensemble variance = rho * sigma squared + (1-rho)/B * sigma squared

Where rho is correlation between trees, sigma squared is individual tree variance, B is number of trees.

By making trees less correlated (random features), we reduce rho, which reduces overall variance. More trees (larger B) also helps, but with diminishing returns.

**My Results:**

- Single Decision Tree: ~91% accuracy
- Random Forest (100 trees): ~96% accuracy
- OOB Score closely matched test accuracy

The decision boundary plot really shows the difference - the forest produces much smoother boundaries than a single tree.
