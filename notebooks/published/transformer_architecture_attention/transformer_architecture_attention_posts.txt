**Title:** I implemented the Transformer attention mechanism from scratch - here's what I learned about the math behind ChatGPT

**Body:**

I built the core attention mechanism from the "Attention Is All You Need" paper using just NumPy. Here's an ELI5 breakdown:

**What is attention?**

Think of it like a smart search. You have:
- Queries (Q): What you're looking for
- Keys (K): Labels on information
- Values (V): The actual information

Attention computes: softmax(QK^T/√d_k)V

This gives you a weighted combination of Values, where the weights depend on how well Queries match Keys.

**Why the √d_k scaling?**

This was my "aha" moment. Without it, the dot products can get huge (variance = d_k). Large values push softmax outputs toward 0 or 1, causing vanishing gradients. Dividing by √d_k keeps variance at 1.

**Multi-head attention**

Instead of one attention operation, we run several in parallel with different learned projections. This lets the model attend to different types of relationships simultaneously.

**Causal masking**

For autoregressive models (like GPT), we mask future positions so the model can't "cheat" by looking ahead. It's just a lower-triangular matrix applied before softmax.

**The quadratic problem**

Attention is O(n²) in sequence length - this is why context windows are limited. My timing tests confirmed the quadratic scaling perfectly.
