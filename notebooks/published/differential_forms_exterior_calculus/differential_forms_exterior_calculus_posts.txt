Title: I built a differential forms calculator in Python - here's what I learned about exterior calculus

Body:

**TL;DR:** Differential forms let you write gradient, curl, and divergence as a single operation called the exterior derivative (d). I implemented this in Python and verified key theorems numerically.

**What are differential forms?**

Think of them as a coordinate-independent way to do calculus. A 0-form is just a function. A 1-form is like a "dual" to a vector field - it eats vectors and spits out numbers. A 2-form measures oriented areas.

**The exterior derivative (d)**

This single operator d does everything:
- Apply d to a function f, you get its gradient
- Apply d to a 1-form, you get something like curl
- Apply d to a 2-form, you get divergence

**The magic: d² = 0**

Apply d twice, you always get zero. This one equation encodes:
- curl(grad f) = 0
- div(curl F) = 0

**What I implemented:**
- A DifferentialForm class storing coefficients and basis elements
- Wedge product with automatic antisymmetrization
- Numerical exterior derivative using central differences
- Verified Stokes' theorem (line integral = area integral)

**Coolest finding:**

The angular form w = (-y dx + x dy)/(x² + y²) on the punctured plane is CLOSED (dw = 0) but NOT EXACT (it's not d of anything). Integrating it around the origin gives 2pi, not zero. This captures the topology - the "hole" at the origin is detected by differential forms!
