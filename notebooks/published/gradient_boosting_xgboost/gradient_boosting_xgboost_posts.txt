### THREADS (< 500 chars)

Ever wonder how XGBoost actually works under the hood?

I built it from scratch to find out. The key insight: gradient boosting does gradient descent in function space, not parameter space.

Each tree learns to correct the errors of ALL previous trees combined. Add regularization on leaf weights and you get XGBoost.

The optimal leaf weight formula: w* = -G/(H + λ)

Where G is the sum of gradients and H is the sum of Hessians. Simple but powerful.

Deep dive into gradient boosting mathematics:

The additive model: F_M(x) = Σₘ γₘhₘ(x)

At each step, we fit a tree to the negative gradient:
rᵢₘ = -∂L(yᵢ,F(xᵢ))/∂F(xᵢ)

XGBoost's innovation: second-order Taylor expansion using both gradient g and Hessian h.

Split gain with regularization:
Gain = ½[G_L²/(H_L+λ) + G_R²/(H_R+λ) - (G_L+G_R)²/(H_L+H_R+λ)] - γ

**Title:** I built Gradient Boosting and XGBoost from scratch to understand how they really work

**Body:**

I've always used XGBoost as a black box, so I decided to implement it from scratch to truly understand the algorithm. Here's what I learned:

**The Core Idea (ELI5):**
Imagine you're trying to hit a target with darts. Gradient boosting is like having 100 people throw darts, where each person aims specifically at correcting the average miss of everyone who threw before them. By the end, the collective aim is incredibly accurate.

**The Math (simplified):**
- Start with a simple prediction (mean of target values)
- Calculate residuals: how much each prediction is wrong
- Train a decision tree to predict these residuals
- Add the tree's predictions (scaled by learning rate) to your model
- Repeat

**What XGBoost adds:**
1. Regularization to prevent overfitting: Ω(f) = γT + ½λΣw²
2. Uses both first AND second derivatives (gradient + Hessian)
3. Clever split-finding with gain formula

**Key insight:** The learning rate controls how much we trust each tree. Small values (0.01-0.1) = slow but steady improvement. Large values (>0.3) = fast but risk overshooting.

**What I built:**
- GradientBoostingRegressorFromScratch: Basic gradient boosting
- XGBoostStyleRegressor: With L2 regularization
- GradientBoostingClassifierFromScratch: Using logistic loss

Test MSE went from terrible to excellent as trees were added. The visualizations really helped me see how residuals shrink at each stage.
