Title: Implemented Einstein Notation and Tensor Calculus in Python using NumPy's einsum

Body:

I created an interactive Jupyter notebook exploring tensor calculus and Einstein's summation convention - the elegant notation that underlies general relativity.

**What is Einstein Notation?**

The key rule: when an index appears twice (once up, once down), you sum over it automatically.

Instead of writing: sum over i of (aᵢ times bⁱ)

You simply write: aᵢbⁱ

**What the notebook covers:**

1. **Basic operations** - inner products, matrix multiplication, tensor contraction using einsum
2. **The metric tensor** - how gᵢⱼ defines geometry in curved spaces
3. **Spherical coordinates** - computed the metric ds² = dr² + r²dθ² + r²sin²θ dφ²
4. **Christoffel symbols** - the connection coefficients needed for covariant derivatives, computed numerically and verified analytically
5. **Stress-energy tensor** - showed T = -ρ + 3p for a perfect fluid in special relativity

**Key insight:** NumPy's einsum() directly implements Einstein notation!

Matrix multiplication Cⁱₖ = AⁱⱼBʲₖ becomes:
```python
C = np.einsum('ij,jk->ik', A, B)
```

The visualization shows tensor transformations, metric geometry on a sphere, and how Christoffel symbols vary with position.
