Title: I built a 1D Density Functional Theory (DFT) solver in Python to understand quantum computational chemistry

Body:

**What is DFT?**

Density Functional Theory is one of the most important methods in computational physics and chemistry. The problem: solving the Schrodinger equation for N interacting electrons requires a wavefunction with 3N coordinates - computationally impossible for real molecules.

DFT's revolutionary insight (Hohenberg-Kohn, 1964): the ground-state properties are uniquely determined by just the electron density n(r), which only has 3 coordinates!

**The Kohn-Sham Trick**

Kohn and Sham (1965) mapped the interacting system to a fictitious non-interacting system with the same density. We solve single-particle equations:

[-1/2 nabla^2 + V_eff(r)] phi_i(r) = epsilon_i phi_i(r)

where V_eff = V_ext + V_H + V_xc includes:
- V_ext: external potential (nuclear attraction)
- V_H: Hartree (classical electrostatic) repulsion
- V_xc: exchange-correlation (all quantum magic)

**What I implemented:**

- 1D finite-difference Kohn-Sham solver
- Self-consistent field (SCF) iteration with linear mixing
- Local Density Approximation (LDA) for exchange-correlation
- Softened Coulomb interaction for Hartree potential

The SCF loop: guess density → build V_eff → solve KS equations → get new density → repeat until converged.

**Key results:**

- Demonstrated SCF convergence to self-consistent ground state
- Visualized how V_eff differs from V_ext due to electron-electron interactions
- Computed HOMO-LUMO gap (which underestimates true gap - known DFT issue)

**Libraries used:** NumPy, SciPy, Matplotlib

I built a simplified version in Python to understand how it works. The algorithm iterates until the electron density becomes "self-consistent" with the forces acting on it.
