**Title:** [Educational] Build an ETL Pipeline from Scratch in Python - Complete Notebook with Visualizations

**Body:**
I created an educational Jupyter notebook that implements a complete ETL (Extract, Transform, Load) pipeline from scratch using Python.

**What you'll learn:**

1. **Extract phase**: Reading from multiple data sources (CSV, JSON, simulated APIs) and handling different formats

2. **Transform phase**:
   - Handling missing values with intelligent imputation
   - Fixing invalid data entries
   - Enriching data by joining reference tables
   - Creating derived features (revenue, profit margins, time dimensions)

3. **Load phase**: Creating aggregated summary tables for analytics

4. **Quality tracking**: Monitoring data quality metrics at each pipeline stage

The notebook includes 4 visualizations showing:
- Pipeline architecture diagram
- Before/after data quality metrics
- Business analytics dashboard
- Pipeline performance metrics

All code is well-commented and uses only standard libraries (pandas, numpy, matplotlib).
