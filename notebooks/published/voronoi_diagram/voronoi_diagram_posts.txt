**Title:** Voronoi Diagrams: Beautiful Math for Spatial Partitioning

**Body:**

Voronoi diagrams are a fundamental data structure in computational geometry with applications ranging from biology to robotics.

**What is a Voronoi Diagram?**

Given n points (called sites or generators) in a plane, the Voronoi diagram partitions the plane into n regions. Each region contains all points closer to one particular site than to any other site.

Mathematically, for site pᵢ, its Voronoi cell is:
V(pᵢ) = {x ∈ ℝ² : d(x, pᵢ) ≤ d(x, pⱼ) for all j ≠ i}

Where d(x,y) is Euclidean distance.

**Geometric Properties**

**1. Half-Plane Representation**

Each Voronoi cell can be expressed as an intersection of half-planes:
V(pᵢ) = ⋂_{j≠i} H(pᵢ, pⱼ)

Where H(pᵢ, pⱼ) = {x : d(x,pᵢ) ≤ d(x,pⱼ)} is the half-plane of points closer to pᵢ than pⱼ.

This guarantees that Voronoi cells are convex polygons!

**2. Perpendicular Bisectors**

The boundary between adjacent cells V(pᵢ) and V(pⱼ) lies on the perpendicular bisector of the line segment connecting pᵢ and pⱼ.

This bisector is: {x : d(x,pᵢ) = d(x,pⱼ)}

**3. Euler's Formula**

For n sites in general position (no four cocircular), the diagram has:
- Vertices: V ≤ 2n - 5
- Edges: E ≤ 3n - 6
- Faces: F = n

Satisfying: V - E + F = 2

**Delaunay Duality**

The Voronoi diagram has a beautiful dual relationship with the Delaunay triangulation:

- Each Voronoi vertex ↔ One Delaunay triangle
- Each Voronoi edge ↔ One Delaunay edge
- Each Voronoi cell ↔ One Delaunay vertex

Key insight: Voronoi vertices are circumcenters of Delaunay triangles. The Delaunay triangulation has the "empty circumcircle property"—no site lies inside the circumcircle of any triangle.

**Implementation Results**

Used scipy.spatial.Voronoi on 25 random sites:

```python
vor = Voronoi(points)
```

Results:
- 41 Voronoi vertices
- 65 edges
- 25 regions
- Average 5.48 edges per cell (theoretical expectation ≈ 6 for random points)

**Handling Infinite Regions**

Scipy returns some regions extending to infinity. I implemented a reconstruction algorithm to:
1. Detect infinite ridges (one vertex at -1 index)
2. Compute direction perpendicular to site-pair midpoint
3. Extend edge to bounding box
4. Close polygons properly

This allows proper visualization and area computation!

**Cell Statistics**

Computed areas using the shoelace formula:
- Mean area: 4.46 square units
- Std deviation: 3.05
- Min: 0.09, Max: 13.67

For uniformly random sites in a bounded domain, cells near boundaries tend to be larger (edge effects).

**Applications**

**1. Nearest Neighbor Search**
Given a query point, find which Voronoi cell it belongs to → that site is the nearest neighbor. Preprocessing: O(n log n), Query: O(log n) with point location.

**2. Geographic Information Systems (GIS)**
- Service area analysis (hospital coverage zones)
- Thiessen polygons for rainfall interpolation
- Territory assignment

**3. Computer Graphics**
- Mesh generation (Voronoi-based quadrilaterals)
- Texture synthesis (Worley noise)
- Procedural generation

**4. Robotics**
- Configuration space decomposition
- Sensor placement optimization
- Coverage path planning

**5. Biology**
- Cellular territory modeling
- Protein structure analysis
- Ecological niche modeling

**6. Materials Science**
- Crystal grain boundary analysis
- Polycrystalline structure simulation

**Complexity**

Fortune's algorithm constructs Voronoi diagrams in O(n log n) time using a sweep line approach. This is optimal since sorting n points requires Ω(n log n).

Space complexity: O(n) for the output structure.

**Variants and Extensions**

- **Weighted Voronoi**: Sites have weights (power diagrams)
- **Higher dimensions**: 3D Voronoi for point clouds
- **Distance metrics**: Manhattan, Chebyshev, Minkowski
- **Farthest-point Voronoi**: Regions farthest from sites
- **Dynamic Voronoi**: Efficient updates as sites move

The elegance of Voronoi diagrams lies in their simple definition leading to rich geometric structure with deep theoretical properties and practical applications.
