### 5. Reddit (r/learnpython or r/MachineLearning)
--------------------------------------------------------------------------------
**Title:** I implemented Support Vector Machines from scratch - here's what I learned about margin maximization

**Body:**

Just finished building an SVM classifier from the ground up using only NumPy and SciPy. Here's the ELI5 version:

**The Core Idea**
Imagine you have red and blue marbles scattered on a table. You want to draw a line separating them. There are infinite lines that work, but SVM finds the ONE line that has the most "breathing room" on both sides. This breathing room is called the **margin**.

**Why This Matters**
A wider margin = better generalization to new data. It's like leaving extra space when parking - more room for error.

**The Math (simplified)**
- We want to maximize 2/||w|| (the margin width)
- Which means minimizing ||w||²
- Subject to all points being correctly classified: yᵢ(wᵀxᵢ + b) ≥ 1

**The Cool Part: Support Vectors**
After training, only ~6% of my data points actually mattered! These "support vectors" are the points sitting right on the margin boundary. Delete any other point? Same classifier. This sparse representation is computationally elegant.

**Results**
- 100% training accuracy
- Clean decision boundary visualization
- Verified KKT optimality conditions

**View the full interactive notebook:** https://cocalc.com/github/Ok-landscape/computational-pipeline/blob/main/notebooks/published/support_vector_machine_svm.ipynb

The notebook includes the complete derivation from primal to dual formulation and a visualization showing the decision boundary, margins, and support vectors.

### 7. LinkedIn (1000 chars)
--------------------------------------------------------------------------------
**Exploring the Mathematics of Support Vector Machines**

Recently completed an implementation of Support Vector Machines from first principles, diving deep into the mathematical foundations that make this algorithm so effective for classification tasks.

**Technical Highlights:**
- Derived the primal optimization problem: minimize (1/2)||w||² subject to margin constraints
- Transformed to dual formulation using Lagrangian multipliers, revealing the elegant property that the solution depends only on inner products between data points
- Implemented using scipy's SLSQP optimizer for quadratic programming
- Achieved 100% classification accuracy with only 6% of training points as support vectors

**Key Insight:** The kernel trick allows SVMs to perform non-linear classification by implicitly mapping data to higher-dimensional spaces. Common kernels include RBF: K(x,z) = exp(-γ||x-z||²) and polynomial: K(x,z) = (xᵀz + c)ᵈ

This project reinforced my appreciation for how mathematical rigor translates to practical machine learning tools. The connection between convex optimization, statistical learning theory, and geometric intuition is particularly elegant.

Full implementation and visualization: https://cocalc.com/github/Ok-landscape/computational-pipeline/blob/main/notebooks/published/support_vector_machine_svm.ipynb
