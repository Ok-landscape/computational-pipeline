**Title:** [Educational] Robot Arm Kinematics from Scratch - Complete Python Notebook with Visualizations

**Body:**
I created an educational notebook that implements robot arm kinematics from first principles for a 2-link planar robot (2R arm).

**Topics covered:**

1. **Forward Kinematics**
   - Compute end-effector (x, y) from joint angles (theta1, theta2)
   - Trigonometric formulation

2. **Inverse Kinematics**
   - Find joint angles to reach a target position
   - Law of cosines approach
   - Multiple solutions (elbow-up vs elbow-down configurations)

3. **Workspace Analysis**
   - Reachable region visualization
   - Inner and outer boundaries

4. **Jacobian Matrix**
   - Relates joint velocities to end-effector velocities
   - Manipulability measure (determinant of J)
   - Singularity analysis

5. **Trajectory Planning**
   - 5th-order polynomial for smooth motion
   - Zero velocity and acceleration at start/end
   - Path visualization in workspace

The notebook includes 4 detailed visualizations showing arm configurations, workspace, trajectories, and manipulability ellipsoids.

Great for students learning robotics fundamentals or engineers wanting to understand the math behind robot motion.

Robot Arm Kinematics: From Theory to Implementation

Understanding robot kinematics is fundamental for anyone working in robotics, automation, or mechatronics. This interactive notebook provides a complete implementation for a 2-link planar robot arm.

Key concepts covered:

FORWARD KINEMATICS: Given joint angles, compute end-effector position using trigonometry

INVERSE KINEMATICS: Given target position, find required joint angles using geometric approach (law of cosines)

JACOBIAN MATRIX: Relate joint velocities to Cartesian velocities. Essential for velocity control and understanding singularities.

TRAJECTORY PLANNING: Generate smooth motion using 5th-order polynomials with zero velocity/acceleration at endpoints

MANIPULABILITY: Analyze where the robot can move freely vs. where it approaches singularities

The notebook generates 4 detailed visualizations including workspace analysis, multiple arm configurations, trajectory planning, and manipulability ellipsoids.
