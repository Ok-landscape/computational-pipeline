TITLE: [OC] Implemented Transfer Learning from Scratch in NumPy - Comparing 4 Fine-Tuning Strategies

BODY:

I built a complete transfer learning simulation using only NumPy to understand what's really happening under the hood. No TensorFlow or PyTorch - just pure math.

**The Setup:**
- Source domain: 1000 labeled samples
- Target domain: Only 100 samples (10x less data)
- Task: 5-class classification with domain shift between source and target

**What I Compared:**

1. **Training from scratch** - No transfer, random initialization
2. **Feature extraction** - Freeze the pre-trained backbone, only train a new classifier head
3. **Full fine-tuning** - Update all layers with a smaller learning rate
4. **Discriminative fine-tuning** - Use different learning rates per layer (smaller for early layers)

**Key Findings:**

All transfer learning methods outperformed training from scratch. The intuition is that neural networks learn hierarchical representations:
- Early layers capture general features (useful across domains)
- Later layers capture task-specific features (need adaptation)

Discriminative fine-tuning uses the formula: η_l = η_base · γ^(L-l) where γ < 1, so earlier layers get smaller updates.

**The Code:**

The notebook includes a from-scratch neural network implementation with:
- Xavier initialization
- ReLU activation
- Softmax + cross-entropy loss
- Mini-batch gradient descent
- Support for freezing layers and layer-wise learning rates

Transfer Learning: Why Starting from Scratch is Often a Mistake

In machine learning, we rarely have unlimited labeled data. Transfer learning addresses this by leveraging knowledge from related tasks.

I recently built a from-scratch implementation in NumPy to explore four fine-tuning strategies:

1. No transfer (baseline) - Train on limited target data only
2. Feature extraction - Use frozen pre-trained features, train only the classifier
3. Full fine-tuning - Update all parameters with reduced learning rate
4. Discriminative fine-tuning - Apply layer-wise learning rate decay

Key technical insight: Neural networks learn hierarchical representations. Early layers capture general features (edges, textures) that transfer well. Later layers learn task-specific patterns requiring adaptation.

The discriminative approach uses: η_l = η_base · γ^(L-l), allowing task-specific layers to adapt while preserving transferable features.

Results: All transfer methods outperformed from-scratch training on limited data, with faster convergence.

Skills demonstrated: NumPy, neural network implementation, backpropagation, optimization theory
