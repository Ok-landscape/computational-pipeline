**Title:** I built a Python tool to hunt for zeros of the Riemann zeta function - here's what I learned

**Body:**

The Riemann zeta function is defined as:

ζ(s) = 1 + 1/2^s + 1/3^s + 1/4^s + ...

Where s is a complex number. This innocent-looking sum connects to prime numbers through Euler's product formula:

ζ(s) = ∏(1/(1 - p^(-s))) over all primes p

**The Riemann Hypothesis** (unsolved since 1859!) says all "interesting" zeros of this function lie on the line where Re(s) = 1/2. These zeros encode information about how primes are distributed.

**What I built:**
- Numerical ζ(s) computation using the Dirichlet eta function (converges better in the critical strip)
- The Riemann-Siegel Z(t) function which is real-valued on the critical line
- Zero-finding via sign changes + Brent's method refinement

**Key results:**
- Found zeros at t ≈ 14.13, 21.02, 25.01, 30.42, 32.94...
- ALL computed zeros lie exactly on Re(s) = 1/2
- The spacing between zeros follows the GUE distribution from random matrix theory

**Mind-blowing fact:** The same statistics that describe energy level spacings in quantum systems describe the gaps between prime-related zeros. Nobody fully understands why.
